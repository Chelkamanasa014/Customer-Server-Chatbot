Customer Service Chatbot 🤖

📌 Project Overview

The Customer Service Chatbot is a simple Python-based application that helps users get quick responses to common customer service questions. It interacts with users through a command-line interface.

🎯 Objectives

- Provide quick responses to customer queries.
- Reduce the time spent answering common questions.
- Demonstrate basic chatbot development using Python.

🛠️ Technologies Used

- Python 3
- Visual Studio Code (VS Code)

✨ Features

- Interactive conversation with users.
- Responds to common queries about orders, delivery, payments, and returns.
- Simple and user-friendly interface.
- Type "bye" to exit the chatbot.

▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python chatbot.py
